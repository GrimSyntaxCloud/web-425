## Live demo and historical source

The old GitHub Pages deployment contained a duplicate Loan Calculator build with a broken base path. The public URL now forwards to the [maintained Loan Calculator](https://grimsyntaxcloud.github.io/loan-app/), which uses patched Angular dependencies. GitHub Pages deploys only the `site/` directory.

The `week-*` folders retain historical coursework. Their original Angular dependencies are not used by this live deployment and have not been upgraded in this maintenance change. Do not deploy those snapshots as current applications without upgrading and testing them first.
